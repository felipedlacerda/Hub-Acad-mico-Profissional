# Poupi

## Categoria
Projeto acadêmico de Engenharia de Software.

## Descrição
Proposta de aplicativo para organização de poupança e acompanhamento de metas financeiras pessoais.

## Problema
O acompanhamento de objetivos financeiros pode ser dificultado pela ausência de ferramentas simples de planejamento e visualização do progresso.

## Objetivo
Desenvolver uma solução digital que auxilie o usuário a planejar e acompanhar metas de economia.

## Funcionalidades propostas
- Cadastro de metas financeiras.
- Definição de valores-alvo.
- Registro de valores poupados.
- Acompanhamento do progresso.
- Visualização das metas cadastradas.

## Requisitos funcionais preliminares
- RF01: Permitir o cadastro de metas.
- RF02: Permitir a definição do valor-alvo.
- RF03: Permitir o registro de valores poupados.
- RF04: Exibir o progresso das metas.

## Requisitos não funcionais preliminares
- RNF01: Interface responsiva.
- RNF02: Navegação simples e intuitiva.
- RNF03: Consistência visual entre telas.

## Design e prototipação
Projeto de interface no Figma, com planejamento de componentes reutilizáveis, wireframes e Design System.

## Etapas previstas
1. Levantamento de requisitos.
2. Desenvolvimento de wireframes.
3. Construção do Design System.
4. Prototipação.
5. Implementação.
6. Testes.
