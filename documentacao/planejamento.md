# Planejamento do Repositório

## Identificação
Nome: Hub Acadêmico & Profissional

Autor: Felipe de Lacerda Pereira

## Objetivo geral
Organizar e documentar projetos acadêmicos e profissionais utilizando Git e GitHub para controle de versão.

## Objetivos específicos
- Centralizar projetos em um repositório.
- Organizar arquivos por categorias.
- Documentar cada projeto.
- Registrar alterações por meio de commits.
- Publicar o portfólio com GitHub Pages.

## Projetos acadêmicos
- Study Hub.
- Poupi.

## Estratégia de versionamento
O repositório utiliza Git para registrar alterações e GitHub para hospedagem remota.

A versão inicial foi identificada pela tag v1.0.0.

Novas alterações serão registradas em commits posteriores.

## Publicação
O portfólio utiliza GitHub Pages.

## Etapas de trabalho
1. Organização do repositório.
2. Documentação dos projetos.
3. Registro das alterações.
4. Publicação e verificação.
5. Apresentação dos resultados.

## Observação
Os projetos são documentados de acordo com seu estágio de desenvolvimento.
