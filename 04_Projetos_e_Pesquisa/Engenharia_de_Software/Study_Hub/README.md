# Study Hub

## Categoria
Projeto acadêmico de Engenharia de Software.

## Descrição
Proposta de plataforma digital para organização e acompanhamento de atividades acadêmicas.

## Problema
Estudantes frequentemente precisam administrar disciplinas, tarefas, prazos e metas utilizando diferentes ferramentas.

## Objetivo
Centralizar informações acadêmicas em um ambiente organizado e de fácil utilização.

## Funcionalidades propostas
- Cadastro de disciplinas.
- Registro de tarefas e prazos.
- Organização de cronogramas.
- Acompanhamento de metas de estudo.
- Visualização do progresso acadêmico.

## Requisitos funcionais preliminares
- RF01: Permitir o cadastro de disciplinas.
- RF02: Permitir o cadastro de atividades.
- RF03: Permitir a definição de prazos.
- RF04: Permitir a atualização do status das tarefas.

## Requisitos não funcionais preliminares
- RNF01: Interface responsiva.
- RNF02: Navegação intuitiva.
- RNF03: Organização consistente das informações.

## Etapas previstas
1. Levantamento de requisitos.
2. Modelagem do sistema.
3. Prototipação.
4. Implementação.
5. Testes e validação.

## Tecnologias
A definir conforme a evolução do projeto.
